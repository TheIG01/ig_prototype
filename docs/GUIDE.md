# Гид по репозиторию

## Что это
Конструктор прототипов сайтов в браузере. Ты собираешь структуру и макеты, потом отдаёшь заказчику просмотр, а нейросети бриф. Данные лежат в твоём браузере, сервера нет.

## Папки
- `src/features/` экраны: `shell` (рамка, настройки, гид), `canvas` (холст, инструменты, правая панель), `blocks` (библиотека блоков), `preview`, `quiz`, `pin`.
- `src/lib/` логика и шаблоны: `tpl*.ts` шаблоны блоков, `export.ts` и `share.ts` экспорт, `measure.ts` размер по содержимому, `tip.ts` подсказки.
- `src/store.ts` данные и действия, `src/styles.css` стили (новое в конце).
- `docs/` для ИИ и для тебя. `.github/workflows/deploy.yml` сам публикует сайт.

## Как обновить сайт (без терминала)
1. Распакуй присланный архив.
2. На GitHub открой репозиторий, «Add file → Upload files», перетащи всё содержимое распакованной папки (включая `.github`), внизу «Commit changes».
3. Если есть `УДАЛИТЬ.txt`, удали эти файлы на GitHub: открой файл, значок корзины, «Commit».
4. Вкладка Actions: жди зелёную галочку (1–2 минуты). Сайт обновится сам, при следующем открытии появится плашка «Обновить».

## Как работать с ИИ и не ждать лимит
- Начинай чат так: приложи zip репозитория и напиши «Прочитай docs/prompts/PROMPT.md и сделай: …». Всё остальное он делает по инструкции.
- Одна задача на один чат. Список правок давай сразу пачкой, не по одной.
- Не проси «улучши всё»: называй, что именно болит. Закончилось место в чате: напиши «СОХРАНИ», забери архив, открой новый чат.
- Просишь экономию: слова «без пояснений» и «только изменённые файлы».

## Сломалось
Сайт не открылся после заливки: Actions, красный крест, скопируй последние строки ошибки в чат. Нужен откат: на GitHub открой прошлый коммит, «Browse files», скачай и залей заново. Данные не пропадут, они в браузере; раз в неделю «Скачать копию».
