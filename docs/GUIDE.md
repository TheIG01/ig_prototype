# Гайд автора: как работать с ИИ над ig_prototype

Всего 12 сессий до финала (версия 1.47 сделана; осталось 1.48–1.58 и 1.59 финал). Тринадцатой не будет. Сессии маленькие под бесплатный лимит.

## Цикл одной сессии (новый чат каждый раз)
1. Открой новый чат Claude.
2. Приложи ОДИН файл: последний `ig_prototype_vX_Y.zip` (из прошлого чата).
3. Отправь стартовое сообщение (копируй целиком, это всё, что нужно писать):

```
Продолжаем ig_prototype. Zip приложен. (версии совпадают)
Прочитай docs/prompts/PROMPT.md и docs/PROGRESS.md и работай строго по ним.
Задача: по плану (следующая версия из PROGRESS).

Сразу начинай работать, и скидывай обновленный файл
```

Если нужна своя задача, замени третью строку: `Задача: <что нужно>`. Скриншоты и пояснения можно добавить ниже.
4. Дождись ответа. ИИ сам сделает версию, обновит журнал и приложит новый полный zip.
5. Скачай новый zip. Следующий чат начинай с него (пункт 1). На GitHub ничего заливать не нужно.

## Если чат оборвался по лимиту
Скачай последний `_wip` архив, который ИИ успел приложить, и начни новый чат с ним. ИИ продолжит ту же версию. Если архива нет, начни с прошлого полного zip. Заранее можно написать **СОХРАНИ**, и ИИ немедленно запишет прогресс и приложит архив.

## Когда обновить сайт (раз в несколько сессий)
1. В новом чате с последним zip напиши одно слово: **ИЗМЕНЁННЫЕ**.
2. ИИ приложит `only_changed_files_vX_Y.zip` (только изменённое с последнего деплоя) и файл `УДАЛИТЬ.txt`, если что-то удалялось.
3. На GitHub: открой репозиторий → Add file → Upload files → перетащи содержимое распакованного архива (папки src и docs перетаскиваются целиком, замена идёт автоматически) → Commit changes.
4. Если есть `УДАЛИТЬ.txt`: открой каждый указанный файл на GitHub → три точки → Delete file → Commit.
5. Зайди во вкладку Actions, дождись зелёной галочки, открой сайт и нажми Ctrl+F5.
6. Вернись в чат и напиши **ЗАЛИТО**. ИИ очистит список «не залито» и пересоберёт zip.
Красная галочка в Actions: скопируй текст ошибки в новый чат с последним zip, ИИ исправит.

## Команды (пиши одним словом)
- **ИЗМЕНЁННЫЕ** собрать архив для GitHub.
- **ЗАЛИТО** сообщить, что обновление на GitHub сделано.
- **СОХРАНИ** сохранить прогресс сейчас.
- **ЧИСТКА** проверить проект на мусор и несостыковки.

## Правила, которые экономят лимиты
- Один чат = одна версия (1–3 задачи). Больше в бесплатный лимит не влезет.
- Всегда прикладывай только самый последний zip.
- Не заливай на GitHub после каждой сессии. Достаточно раз в несколько сессий.
- Если не помнишь, какой zip последний: по номеру версии в имени и по дате.

## Что где лежит
- `docs/PROGRESS.md` состояние проекта и список «не залито».
- `docs/prompts/PROMPT.md` главный промпт.
- `docs/prompts/roadmap.md` план: 1.48–1.58, 1.59 (финал) и бэклог после финала.
- `docs/prompts/figma_hotkeys.md` горячие клавиши и когда они появятся.
- `docs/archive/` старые журналы (ИИ их не читает).
- `docs/refs/ui_refs.md` скриншоты Tilda и Figma, описанные словами (картинок в проекте нет, zip лёгкий).
