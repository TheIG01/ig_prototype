## 2. Что уже есть
- Проект → лист → блок, холст, слои, группы (Ctrl+G, вход двойным кликом, Ctrl+клик), общие свойства, колонки 4/8/12 и привязка, рулеры.
- Горячие клавиши: R, O, T, L, V, Shift+A, Ctrl+G/D/C/V/Alt+C/Alt+V, Space, +/−, отражение, [ ], Ctrl+Shift+H/L, Alt+L.
- Элементы: text, rect, btn, input, img, line, shape, icon, mock, list. Автоподгонка (hug, равные размеры), шкала отступов.
- Библиотека блоков (99 шаблонов), избранное, сортировка, отражение при вставке.
- Типограф RU/EN, проверка текста (140 символов, «вы/вас/вам/ваш», «!», «не/нет»), режим «Лёгкий», виртуальные списки слоёв.
- Экспорт: ТЗ для ИИ (Markdown, JSON), HTML одним файлом, PDF-отчёт, просмотр с кликабельными кнопками. Скрытые элементы в экспорт не попадают.
- Честное сохранение: статус «Сохранено/Не сохранено», запись по очереди, запись при закрытии, вторая вкладка только для чтения.
- 1.47: глаз и замок у элемента и группы, левая панель «Блоки | Слои» (дерево блок → группа → элемент).

Сессия 58 (1.47):

- Новые файлы: `src/features/canvas/LayerBtns.tsx`, `layers.css`, `src/features/shell/LayersTab.tsx`.
- Проверено: `npm install` без сети оборвался, `react`, `zustand`, `immer`, `lucide-react`, `@types/react` в node_modules пустые. `tsc` и `vite build` НЕ запускались (нет типов). Запускалась только проверка синтаксиса всех 54 файлов `src` через `ts.transpileModule`: ошибок 0. Playwright не запускался, в браузере не смотрел.
- Не сделано (перенесено): перетаскивание в слоях и папки (1.48); переименование, Enter/Shift+Enter, Ctrl+Alt+A, Ctrl+Shift+A, зона под блоком, виртуальный список во вкладке «Слои».

Скрытое элемент по-прежнему занимает место в авто-лейауте.

Подготовка процесса (версия не менялась, остаётся 1.47): добавлен `docs/MAP.md`; PROMPT переведён на режим «только изменённые»; полный архив собирает автор у себя.
