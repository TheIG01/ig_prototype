## 2. Что уже есть
- Проект → лист → блок, холст, слои, группы (Ctrl+G, вход двойным кликом, Ctrl+клик), общие свойства, колонки 4/8/12 и привязка, рулеры.
- Горячие клавиши: R, O, T, L, V, Shift+A, Ctrl+G/D/C/V/Alt+C/Alt+V, Space, +/−, отражение, [ ], Ctrl+Shift+H/L, Alt+L.
- Элементы: text, rect, btn, input, img, line, shape, icon, mock, list. Автоподгонка (hug, равные размеры), шкала отступов.
- Библиотека блоков (99 шаблонов), избранное, сортировка, отражение при вставке.
- Типограф RU/EN, проверка текста (140 символов, «вы/вас/вам/ваш», «!», «не/нет»), режим «Лёгкий», виртуальные списки слоёв.
- Экспорт: ТЗ для ИИ (Markdown, JSON), HTML одним файлом, PDF-отчёт, просмотр с кликабельными кнопками. Скрытые элементы в экспорт не попадают.
- Честное сохранение: статус «Сохранено/Не сохранено», запись по очереди, запись при закрытии, вторая вкладка только для чтения.
- 1.47: глаз и замок у элемента и группы, левая панель «Блоки | Слои».
- 1.48: перетаскивание слоёв мышью (выше / ниже / в папку), «Папка из выбранного», открытые папки запоминаются в блоке (поле `Block.fo`).

## 3. Открытые задачи и недочёты
- План 1.49–1.59 в `docs/prompts/roadmap.md`. Перенесённое из 1.48 в бэклог: вход в группу из слоёв, виртуальный список во вкладке «Слои».
- Перетаскивание слоёв работает мышью (стандартный HTML5 drag). На телефоне и планшете с касанием оно не работает: нужен отдельный способ (в бэклоге).
- Папка = группа элементов (`El.g`). Пустой папки без элементов пока нет.
- Плейсхолдеры без работы: таймер, счётчик мест, видео, ползунок, фото/аватары в шаблонах (закроются в 1.56–1.57).
- НЕ компилировалось: версии 1.47 и 1.48. Нет сети, `node_modules` не ставится. `tsc` и `vite build` не запускались. Не проверялось: Safari, Firefox, телефон, браузер вообще.
