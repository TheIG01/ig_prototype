У автора: комментарии (клавиша C) → «Заметки заказчика» → выбрать файл: заметки встают пинами с подписью заказчика (`lib/clientNotes.ts`, `replaceProject`, отмена Ctrl+Z). Повторная загрузка не дублирует. Блок ищется по id: файл должен быть от этого же проекта.
