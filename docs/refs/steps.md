# Группа «Этапы» (v1.14)

Референсов по этапам не было: варианты собраны по правилам автора и типовым паттернам блока «Как мы работаем». Тексты: пример-ниша бассейны, автор заменяет своим. Для 3–7 этапов берутся первые n из 7: Заявка, Замер и смета, Договор, Монтаж, Запуск, Обучение, Гарантия.
Процент это экспертный ориентир (доля дошедших до блока, кто нажмёт кнопку или оставит телефон), не измерение. Проверять на реальном трафике.

| # | Вариант | Ориентир | Обоснование |
|---|---|---|---|
| 1 | Табы горизонтально (лучший) | 3,5–5 % | Человек сам выбирает этап, вовлечён, экран короткий, внутри вкладки срок, результат и кнопка |
| 2 | Табы вертикально (лучший) | 3–4,5 % | То же, но влезают 6–7 этапов и длинные названия |
| 3 | Линия | 2,2–3,2 % | Весь путь виден сразу, но описаний мало, кнопка внизу |
| 4 | Таймлайн | 2,5–3,5 % | Подробно, фото объекта и кнопка рядом, но длинный |
| 5 | Карточки | 2–3 % | Читается по отдельности, нет ощущения пути |
| 6 | Аккордеон | 1,8–2,8 % | Компактный, но нужно нажимать, чтобы читать |
| 7 | Результат | 2,5–3,8 % | Для сложных заказов: что делаем, срок, что получаешь |
| 8 | С формой | 4–6 % | Форма рядом с этапами, заявка без ухода с экрана; не любимый по заданию, но по заявкам сильный |

## Как работают табы
- Каждая вкладка это отдельный блок (`Block.sv = {v,g,i,n,tab}`); в просмотре виден только блок активной вкладки, у кнопок вкладок `El.tg = "группа:номер"`.
- Число этапов 3–7 меняется в панели блока (`setSteps`). Вкладки добавляются и убираются блоками, тексты, которые правил автор, сохраняются (`El.sk` ключ текста).
- «Добавить блок в этот этап» или «Показывать в этапе» кладёт любой блок внутрь вкладки (`sv.x = 1`).
- Мобилка: вкладки номерами (горизонтальные) или список строк (вертикальные), название этапа внутри блока.
