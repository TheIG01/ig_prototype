# Квизы: разбор 19 референсов (сессия 29)

Дизайн не смотрели: только элементы, роли, слоты, варианты, адаптив. Все блоки собираются из настроек (`block.quiz`, окно «Настроить квиз»), а в просмотре проходятся по кнопкам.

## Кластеры референсов
1. **4 поколение** (скрины 1–5, 11, 12): подбор решений. Сверху полоса «Расчёт пройден на N%», вопрос с бейджем «Вопрос N из M», карточки с фото, справа консультант с фразой на каждый шаг, счётчик «Осталось N решений» (38 → 21 → 14 → 9 → 4), карточка подходящего решения, плашки выбранных ответов, скидка растёт (500 ₽ за ответ), список «В конце получите». Финал: «Система подобрала 4 решения», телефон с напоминанием про закреплённую скидку, экран «Собираем результат».
2. **3 поколение** (8, 13, 15, 16, 17): подарки плашками над квизом, «За каждый ответ скидка 2%», менеджер справа, карточки с фото и вариант «Затрудняюсь ответить».
3. **2 поколение** (7, 9, 10, 18): простой список, «Осталось N вопросов из M», «По окончании теста вы получите», «Пропустить вопрос», картинка-подсказка справа.
4. **Диалог с менеджером** (14, 19): вкладки «Вопрос 1…5», менеджер с приветствием, три результата справа.
5. **Бриф-квиз** (6): текстовые поля и список сфер. В библиотеку не взят: ручной ввод нарушает правило «вводить только телефон».
6. Финал-форма (5): стикер подарка, таймер «исчезнет через 13:46», три выгоды, папка с расчётом.

## Варианты в библиотеке (группа «Квизы»)
| Вариант | Для чего | Ориентир конверсии (посетитель → заявка) | Почему |
|---|---|---|---|
| **Квиз 4 поколения: подбор решений** (лучший) | трафик из рекламы, дорогой чек | 12–18% | Счётчик и карточка решения дают ощущение подбора, консультант снижает тревогу, скидка и таймер подталкивают оставить номер |
| Квиз 3 поколения: скидка за ответы | средний чек, акции | 9–14% | Растущая скидка мотивирует дойти до конца, но нет эффекта персонального подбора |
| Квиз 2 поколения: классика с подарками | холодный трафик, простая ниша | 6–10% | Просто и понятно, но нет живых элементов и дожима |
| Квиз-диалог: вкладки и менеджер | услуги, где важно доверие к человеку | 8–12% | Вкладки показывают объём, менеджер даёт лицо; нет счётчика решений |
| Мини-квиз в одну колонку | попап, мобильный трафик, узкие места на лендинге | 7–11% | Минимум элементов, быстро проходится, помещается в экран |

Это ориентиры по опыту рынка, а не замеры: сверяй со своей статистикой.

## Что добавлено сверх референсов (все включаются в настройках)
Стикер подарка, таймер подарка на шаге телефона (идёт в просмотре по-настоящему), дефицит «осталось 3 места», соцдоказательство, кнопки WhatsApp и Telegram в финале, вопрос-прокладка «Куда отправить результат», строки загрузки по очереди, «Что будет дальше» на финале, ответ сразу ведёт дальше, проверка по правилам автора.

## Правила автора в коде
4–6 вопросов, от простого к сложному, вариант «Не знаю / нужна консультация», руками только телефон, без маски, напоминание про закреплённый за номером подарок, цифра в заголовке считается сама (`{qw}`), мобилка помещается в 844 px. Вкладка «Проверка» показывает, что нарушено.
