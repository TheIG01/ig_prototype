# Референсы интерфейса словами (вместо скриншотов)

## Tilda Zero Block (редактор)
1. **Zero Block на странице.** Над блоком кнопки «Настройки» и «Редактировать блок» (оранжевая). Справа вверху блока мини-панель: дубликат, удалить, вкл/выкл, меню, стрелки вверх и вниз. Над страницей панель форматирования текста: жирный, курсив, подчёркнутый, зачёркнутый, ссылка, нумерованный и маркированный список, пипетка/маркер, выравнивание, кнопка ИИ, ластик, меню «...», справа шрифт и размер («100px, Arial»). Текст редактируется прямо на странице.
2. **Левая панель: вкладки «Слои» и «Блоки».** «Блоки» это список блоков страницы, каждый со значком молнии и именем «Блок #номер». Выбранный блок подсвечен серым.
3. **Вкладка «Слои».** Плоский список слоёв выбранного блока: значок типа слева (T текст, картинка, квадрат фигура), имя («Zero Block», «Tilda Publishing», «bz1.svg», «Фигура 1»). Каждая строка в светлой плашке с тонкой границей.
4. **Тип поля формы (выпадающий список).** Пункты со значками: Email, Телефон, Имя, Поле в одну строку, Поле в несколько строк, Выпадающий список, Вопрос с вариантами ответа, Вопрос с вариантами в виде картинок, Галочка, Файл, Файл (uploadcare), Дата, Время, Количество (кнопки плюс/минус), Количество (ползунок), Ссылка, Текстовый комментарий, Отступ, Скрытое поле, Калькулятор. Справа в панели блок «Поля ввода» (кнопка), «Сервисы» (приём данных), «Форма» (ориентация, стиль полей).

## Figma (панели)
5. **Дерево слоёв.** Иерархия с отступами и стрелками раскрытия: «320-480» (секция с пунктирной рамкой), внутри «Group 739», в нём «Frame 503», «Frame 454» (значок решётки = фрейм) и «Rectangle 890» (значок прямоугольника). Выбранная строка подсвечена голубым.
6. **Панель свойств группы сверху вниз:** заголовок «Group» и справа значки (код, компоненты, маска, вид); Position (кнопки выравнивания: 3 по горизонтали, 3 по вертикали, распределение; поля X и Y; Rotation и кнопки отражения); Layout (Flow: четыре режима: свободно, вертикально, горизонтально, сетка; Dimensions W и H, значок пропорций); Appearance (Opacity 100%, Corner radius 0, кнопка радиусов по углам, глаз); Fill (цвет D9D9D9, 100%, глаз, минус; плюс добавляет заливку); Stroke и Effects (свёрнутые, плюс справа); Selection colors; Export (плюс).
7. **Нижняя часть той же панели:** Appearance, Fill, Stroke, Effects, Selection colors (список цветов выбранного), Export. Секции разделены тонкими линиями; заголовок секции серый, значения в светло-серых полях.

## Наш сервис (проблема)
8. **Зона под блоком.** На холсте страница «Главная · Desktop · 1440»: один блок 1440×488, под ним ещё большая пустая белая область страницы (около 200 пикселей высоты) с пунктирной кнопкой «+ Добавить блок (A)» по центру. Автор обвёл эту пустоту красным: она лишняя. Решение: высота страницы = содержимое, вставка блока тонкой полосой между блоками при наведении и одна кнопка в конце.
