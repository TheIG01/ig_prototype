# Дальше (по порядку пользы; брать сверху)

Выбор только то, что экономит время при главной задаче: быстро собрать прототип и отдать бриф нейросети.

## Следующие версии
1. **Пакет для нейросети под конкретный сервис.** Кнопка «Для ИИ» даёт готовый промпт под выбранный инструмент (сайт в Claude, v0, Lovable, Cursor): бриф, структура, стиль, что нельзя менять. Ядро ценности сервиса, делается за одну сессию, лимит не тратит.
2. **Снимки версий.** «Зафиксировать версию» перед правками заказчика, список снимков, вернуть любой. Страховка вместо страха сломать.
3. **Автобэкап.** Раз в неделю плашка «Скачай копию» и запись в выбранную папку (File System Access API, где доступно).
4. **Компоненты с экземплярами.** Правка мастера меняет все копии (кнопка шапки, футер). Сейчас связь с библиотекой одноразовая.
5. **Карта сайта.** Схема листов и переходов, собирается сама из ссылок кнопок. Показывает висячие страницы.
6. **Поиск и замена текста** по проекту (название компании, телефон, город) с предпросмотром.
7. **Состояния элементов** (наведение, открытый пункт FAQ, ошибка поля) в просмотре.
8. **Стрелки с привязкой** к элементам и обрезка содержимого фрейма.
9. **Ленивая загрузка `tpl*.ts`** (меньше начальный бандл) и офлайн-шрифты в HTML.
10. **Заметки заказчика файлом:** заказчик возвращает файл комментариев, они встают пинами на холст.

## Не делать
Облако, регистрация, совместный доступ в реальном времени, платные API: ломают «только статика» и бесплатный тариф. Анимации и переходы между экранами сложнее простого фейда: прототипу не нужны.

## Бэклог мелочей
Перетаскивание слоёв касанием; ручки масштаба повёрнутого элемента считают по осям до поворота; настройка отступов Hug (сейчас 24/14 px по бокам); вкладки «Элемент / Стиль» в правой панели.
