# Горячие клавиши (как в Figma) и план их внедрения

Источник: список автора. Колонка «Вер.» это версия (сессия) из roadmap.md (1.48–1.58, 1.59 финал); «бэклог» не входит в 12 сессий, где клавиша делается. «Есть» означает, что клавиша уже работает по журналу до 1.46 (перед работой проверить grep по `e.code`). Ctrl = Cmd на Mac.
Правила: по `e.code`; не срабатывают в полях ввода и при редактировании текста; в настройках можно посмотреть список (окно «Горячие клавиши» по `?`), переназначение в бэклоге.

## Замечания по опечаткам в исходном списке (решения)
- «Найти предыдущий фрейм» у End: принято как «последний блок» (Home первый, End последний).
- В списке автора и 100%, и 0% записаны как «0»: принято как в Figma: 0 = 100%, быстрое двойное 00 = 0%. Shift+0 занят масштабом 100%.
