# Режим УЛУЧШИ: один проход по UI/UX (docs/prompts/PROMPT.md)

Цель: сервис и библиотека блоков выглядят и ощущаются как профессиональный инструмент уровня Figma/Tilda. Ничего не ломать, данные старых проектов открываются (миграции только необязательными полями).

## Порядок (останавливайся, когда кончается бюджет, сохраняй)
1. **Токены.** Проверь `styles.css`/`polish.css`: один набор переменных (цвета, радиусы 4/8/12, тени, отступы 4/8/12/16/24, шрифтовая шкала 12/13/14/16/20). Разбросанные числа заменить на токены. Новое в `polish.css`.
2. **Рамка.** Шапка, левая панель (Слои / Блоки), правая панель, статусы сохранения: выравнивание, высоты строк 32/36, hover/active/focus/disabled у каждой кнопки, видимый фокус с клавиатуры, подсказки.
3. **Библиотека блоков** (`features/blocks/blocks.tsx`): сетка карточек ровная, одинаковые пропорции превью, понятный выбор группы, поиск, избранное и «недавние» сверху, пустые состояния с подсказкой, быстрые превью без дёрганья.
4. **Макеты самих блоков** (`lib/tpl*.ts`): отступы по сетке 8, одинаковые поля у секций (ПК 1440: 120 по бокам или единая колонка 1200; планшет 768: 48 (решено в сессии 68, кратно 8); мобилка 390: 20), заголовок не шире 2–3 строк, кнопки одной высоты (ПК 56, мобилка 52), ничего не налезает и не обрезается на всех трёх размерах. Проверь все группы скриптом (Node): наложения элементов, выход за границы, высота меньше экрана.
5. **Скорость.** Ленивая загрузка тяжёлого, мемоизация карточек библиотеки, виртуальный список при длинных группах, размер бандла в отчёте до и после.
6. **Мобильная и узкие окна.** Меню «Ещё», панели, касания 44 px.

## Скрипт проверки блоков
`npx tsx scripts/checkBlocks.ts`: наложения текстов, выход за границы 1440/768/390, пустые размеры. Сессия 65: 99 блоков, 0 замечаний. Кнопки в данных: `t==="btn"`.

## Критерий готово
Сборка зелёная, скрипт проверки блоков без ошибок, в отчёте цифры: сколько блоков проверено, сколько исправлено, размер бандла.
