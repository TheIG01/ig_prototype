# Правила проекта (читать вместе с docs/PROGRESS.md; порядок работы и выдача в docs/prompts/PROMPT.md)

Проект ig_prototype: личный инструмент автора для прототипов сайтов клиентов агентства (лендинги, многостраничники, магазины, квизы). Прототип чёрно-белый. Только статика на GitHub Pages, бесплатно, без серверов и воркеров. Автор новичок в коде: только заливает файлы на GitHub.

## Экономия лимитов
- Читать только: PROGRESS.md, этот файл, раздел нужной версии в roadmap.md. Архив и `docs/refs/ui_refs.md` только по просьбе. Картинок в проекте нет.
- Точечные правки (grep, str_replace). Не перечитывать и не переписывать файлы целиком. Крупные файлы (`Canvas.tsx`, `store.ts`, `styles.css`) не раздувать: новое в новые файлы.
- Проверки только по изменённому. Не собирать скриншоты «на всякий случай». Не делать text.ru и тяжёлых анализов текста (правило 140 символов проверять по месту).
- Ответы короткие. Один вопрос автору, только если без ответа нельзя.
- Честность: писать только реально запущенные проверки (tsc, vite build, Node, Playwright).

## Правила кода
- TypeScript strict, без `any`, без `console.*` в коде сервиса, без `confirm/alert/prompt`.
- Новые функции модели элемента (`El`) добавляй необязательными полями и обработкой в `lib/migrate.ts`, чтобы старые проекты открывались.
- Тяжёлое (иконки, редактор пера, карта, таблицы) грузить лениво (`lazy`, динамический `import`).
- Каждая правка модели данных: проверить экспорт (бриф Markdown и JSON, HTML, PDF) и просмотр.
- Горячие клавиши: по `e.code`, не срабатывают в полях ввода; не конфликтуют с браузером (если конфликт, `preventDefault` только для безопасных сочетаний, иначе запасная клавиша и запись в `figma_hotkeys.md`).

## Постоянные правки автора
- Интерфейс только на русском. Тексты с глаголом в действии, без «Вы», без восклицаний. В подсказках обращение на «ты».
- Никаких системных окон браузера (confirm, prompt, alert): только свои плашки.
- Блок это настоящий макет, не пустая полоса с названием. Важные элементы крупнее, неважные меньше. Текст не мелкий, читаемый, не обрезается в редакторе.
- Шаблон «эксперт» удалён, не возвращать.
Нравится: стиль IG calendar, редактор как в Figma, блоки как в Tilda, но удобнее; блоки по группам; проект → лист → блок; первые экраны по формуле; подсказки по конверсии.
Не нравится: системные окна; пустые блоки-полосы; путаница «страница» и «блок»; мелкие подписи; плашки с текстом в углу; обрезанный текст.

## Тексты и первый экран
Все тексты по `docs/prompts/copywriting.md`. Правила блоков: шапка до 10% первого экрана (логотип, дескриптор, телефон, «Перезвоните мне»); форма: только телефон, подсказка над полем, галочка согласия, кнопка совпадает с заголовком формы, формы каждые 2–3 блока не одинаковые; квиз: 4–6 вопросов от простого к сложному, вариант «Не знаю / нужна консультация», перед телефоном вопрос «куда отправить результат», напоминание про подарок, страница «Спасибо» с прогревом; цифра в заголовке равна числу обещанного.
