# Правила работы в чате (читать первым вместе с PROGRESS.md)

Проект ig_prototype: React 18, TypeScript strict, Vite 5, Zustand + Immer, GitHub Pages. Личный инструмент автора (как Figma, Moqups, Tilda, только лучше) для прототипов сайтов клиентов агентства: лендинги, многостраничники, магазины, квизы. Прототип чёрно-белый: согласуем структуру и тексты, потом бриф уходит в нейросеть для дизайна и вёрстки. Автор новичок в коде: только заливает файлы на GitHub. Ничего не продаём, сервис нужен только ему, пользуется каждый день.

## Ограничения
Только статика (GitHub Pages), полностью бесплатно, без серверов и платных API. Все устройства и браузеры, светлая тема, акцентный синий, минимализм. Плавные анимации, ничего не съезжает. Каждая функция доведена до 100%, без заглушек, похожих на готовое. Актуально на 2026 год.

## Экономия лимитов (важно)
- Версия = 1–3 законченные задачи. Точечные правки (grep и str_replace), не перечитывать и не переписывать файлы целиком.
- Не делать лишних проверок. Всегда: `tsc --noEmit` по изменённым файлам. Геометрия в Node и один прогон Chromium со скриншотами только для новых или изменённых шаблонов и раскладок. Не повторять проверки того, что не менялось. Не собирать листы скриншотов «на всякий случай». `vite build` в окружении невозможен (нет node_modules и сети), не пытаться.
- Не делать text.ru и тяжёлых автоматических анализов текста: правило 140 символов проверять по месту.
- Отдавать только изменённые файлы. Ответы короткие: что сделано, что проверено, что делать. Один вопрос, только если без ответа нельзя.
- Честность: не писать «проверено в браузере», если не проверял. Указывать точно: tsc, тесты в Node, Playwright в Chromium (упрощённая разметка или реальный редактор).

## Порядок работы
1. Автор загружает полный `ig_prototype_vX_Y.zip`. Ответить одной фразой: «Прочитал. Сайт на версии X.Y. Что делаем?» (прочитав docs/PROGRESS.md, docs/prompts/*.md; tpl*.ts только по необходимости).
2. Для групп референсов: 1 лучший вариант (самый конверсионный) + до 4 дополнительных, у каждого оценка % конверсии с обоснованием. Дизайн референсов не смотрим, только элементы, роли, слоты, варианты, адаптив. Разбор в `docs/refs/<группа>.md`, шаблоны в `src/lib/tpl<Группа>.ts`, подключение в `tpl.ts` по образцу `tplFirst.ts`.
3. В конце два архива: полный `ig_prototype_vX_Y.zip` и `only_changed_files_vX_Y.zip` (только изменённые файлы с точным списком путей). Автор заливает второй. Обновить `docs/PROGRESS.md`.

## Формат ответа
Обновление: что загрузить и что нажать. Первый запуск или внешний сервис: пошаговый гайд. Обязательно: что нравится и что не нравится в последних правках. В конце журнал сессии: номер, версия, сделано, проверено, не сделано или сломано, решения и правки автора, изменения структуры файлов, что дальше (3–7 пунктов), блок «Как обновить».
Как обновляет автор: распаковывает only_changed, на GitHub Add file → Upload files, перетаскивает src и docs с заменой, Commit, ждёт зелёную галочку в Actions, Ctrl+F5.

## Постоянные правки автора
- Интерфейс только на русском. Тексты с глаголом в действии, без «Вы», без восклицаний. В подсказках обращение на «ты».
- Никаких системных окон браузера (confirm, prompt, alert): только свои плашки.
- Блок это настоящий макет, не пустая полоса с названием. Важные элементы крупнее, неважные меньше. Текст не мелкий, читаемый, не обрезается в редакторе.
- Шаблон «эксперт» удалён, не возвращать.
Нравится: стиль IG calendar, редактор как в Figma, блоки как в Tilda, но удобнее; блоки по группам; проект → лист → блок; первые экраны по формуле; подсказки по конверсии.
Не нравится: системные окна; пустые блоки-полосы; путаница «страница» и «блок»; мелкие подписи; плашки с текстом в углу; обрезанный текст.

## Тексты и первый экран
Все тексты по `docs/prompts/copywriting.md`. Правила блоков: шапка до 10% первого экрана (логотип, дескриптор, телефон, «Перезвоните мне»); форма: только телефон, подсказка над полем, галочка согласия, кнопка совпадает с заголовком формы, формы каждые 2–3 блока не одинаковые; квиз: 4–6 вопросов от простого к сложному, вариант «Не знаю / нужна консультация», перед телефоном вопрос «куда отправить результат», напоминание про подарок, страница «Спасибо» с прогревом; цифра в заголовке равна числу обещанного.
