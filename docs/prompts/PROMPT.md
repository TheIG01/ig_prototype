# ПРОМПТ ig_prototype (читать первым, коротко)

Проект работает. Задача: улучшать, НЕ ломая. Стек: React 18, TypeScript strict, Vite 5, Zustand+Immer, PWA, GitHub Pages (`/ig_prototype/`). Без серверов и платных API. Интерфейс на русском, на «ты», без «Вы» и восклицаний, без `alert/confirm/prompt`. Светлая тема, синий акцент, минимализм. Автор новичок, лимит бесплатный.

## Порядок (экономно)
1. Распакуй zip, прочитай только `docs/PROGRESS.md`.
2. Задача из сообщения автора, иначе из `docs/prompts/roadmap.md` (раздел «Дальше»).
3. Где что: `grep` по `docs/MAP.md`, затем `view` ±40 строк. `Canvas.tsx`, `store.ts`, `styles.css`, `tpl*.ts` целиком не читать. Новое класть в маленькие файлы. Стили добавлять в конец `styles.css`.
4. Тексты шаблонов только по `docs/prompts/copywriting.md`, вкусы автора в `docs/prompts/work_rules.md`; читать, только если трогаешь тексты или внешний вид.
5. Не пересказывай документы, вопросов не задавай, решай сам.

## Проверка
`npm install`, затем `npx tsc --noEmit && npx vite build`, вывод в файл, в ответ последние 5 строк. Пиши только то, что реально запускал.

## Выдача
Один zip с ИЗМЕНЁННЫМИ файлами (те же пути, без `node_modules`, `dist`, `.git`), название `ig_vX_Y_changed.zip`, плюс `УДАЛИТЬ.txt`, если что-то удалялось. Версию в `package.json` и `docs/PROGRESS.md` повышай, только когда сборка зелёная. `PROGRESS.md` перезаписывай (до 5 КБ). `MAP.md` правь, только где менялись файлы.

## Команды автора
**СОХРАНИ** записать прогресс и выдать архив сразу. **ЧИСТКА** найти мусор, дубли, мёртвый код. **ЗАЛИТО** записать «версия залита».

## Размер сессии
До 3 задач, остальное в «Дальше» в roadmap.
